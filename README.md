# Planlayıcım

Günlük görevleri planlamak, takvim üzerinden takip etmek  için yapılan bir planner web sitesi.

## Kullanılan şeyler

- HTML
- CSS
- JavaScript (sonra eklenecek)
- Flask (sonra eklenecek)
- PostgreSQL (sonra eklenecek)

## Şu anki durum

Proje şu an taslak aşamasında. Sadece HTML ve CSS ile yapılmış 3 sayfa var:

- Ana Sayfa (`index.html`)
- Görevlerim (`gorevler.html`)
- Görev Ekle (`gorev-ekle.html`)

## Nasıl çalıştırılır

1. Depoyu bilgisayarına indir:

```
git clone https://github.com/KULLANICI_ADIN/planner.git
```

2. Klasörün içine gir.
3. `index.html` dosyasını tarayıcıda aç.

Şimdilik başka bir şey kurmaya gerek yok.

## Klasör yapısı

```
planner/
├── css/
│   └── stil.css
├── img/
├── index.html
├── gorevler.html
├── gorev-ekle.html
└── README.md
```
